This directory contains the raw production observations used by the ProdAssist research demonstrator.

`production_data.csv` is synthetic data created for software development, testing and research prototyping.

It contains 36 observations covering:

- production performance
- downtime
- quality
- machine condition
- production context

The raw dataset intentionally contains observations rather than derived conclusions.

Output deviation, defect rate, severity, explanations and recommendations are calculated by the analytical layer.
